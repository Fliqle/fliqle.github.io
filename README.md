Personal site of Valera Sirotkin — designer, art director, and musician.

This repo also doubles as a personal sandbox: a place to learn and play with code, not just a polished production site. Expect a mix of real content and experiments.

## Stack

- [Next.js 15](https://nextjs.org) (App Router, Turbopack) + React 19
- TypeScript
- Tailwind CSS 4

## Structure

- `app/page.tsx`, `app/en/page.tsx` — home page (Russian and English versions)
- `app/about/page.tsx` — work experience page
- `app/projects/` — individual case study pages
- `app/layout.tsx` — shared layout (header, avatar, metadata)
- `public/` — images and other static assets
